# AR-handbutton

AR-handbuttonは、Three.jsとWebXR APIを使用して構築された、VR（仮想現実）でのハンドトラッキングによるボタン操作デモです。

## デモ
デモは https://code4fukui.github.io/ar-handbutton/ でご覧いただけます。

## 特徴
- AR/VR空間において、手を使って仮想ボタンを押すことができます。
- ボタンを押した際に、触覚フィードバックと効果音を提供します。
- インタラクティブな3Dオブジェクトの例として、回転するキューブが含まれています。

## 必要条件
- AR/VR機能を備えたデバイス上の、WebXR対応ウェブブラウザ（例: Chrome, Firefox）

## 使い方
プロジェクトをローカルで実行するには：

1. リポジトリをクローンします：
   ```
   git clone https://github.com/code4fukui/ar-handbutton.git
   ```
2. ウェブブラウザで `index.html` を開きます。
